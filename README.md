# SortInC

Лабораторная работа по реализации и сравнению алгоритмов сортировки на языке C.
Автор: Александр Сыроватский, студент Томского государственного университета.

## Описание

Интерактивная программа генерирует массив случайных целых чисел, сортирует его выбранными алгоритмами по возрастанию, проверяет корректность результата и замеряет время работы каждого алгоритма. Так можно наглядно сравнить скорость простых квадратичных сортировок и сортировки слиянием.

Все выбранные алгоритмы сортируют **копии одного и того же исходного массива**, поэтому сравнение времени получается честным.

## Реализованные алгоритмы

| № | Алгоритм | Функция | Сложность (в среднем) |
|---|----------|---------|-----------------------|
| 1 | Простейшая («глупая») сортировка | `stupidSortASC` | O(n³) |
| 2 | Обменная (пузырьковая) | `bubbleSortASC` | O(n²) |
| 3 | Вставками | `insertionSortASC` | O(n²) |
| 4 | Выбором | `selectionSortASC` | O(n²) |
| 5 | Слиянием | `mergeSortASC` | O(n log n) |

### Основные функции

- `createRandArr(size, randMin, randMax)` — создаёт динамический массив из `size` случайных чисел в диапазоне `[randMin, randMax]`. Возвращает `NULL`, если диапазон некорректен или не удалось выделить память. Память нужно освободить через `free()`.
- `isSortedArr(arr, size)` — проверяет, отсортирован ли массив по возрастанию.
- `stupidSortASC`, `bubbleSortASC`, `insertionSortASC`, `selectionSortASC` — сортировки массива по возрастанию «на месте»; принимают указатель на массив и его размер.
- `mergeSortASC(arr, left, right)` — сортировка слиянием для отрезка массива `[left, right]`.
- `wrappedMergeSort(arr, size)` — обёртка в `main.c`, приводящая `mergeSortASC` к общему типу `SortFunc`, чтобы все алгоритмы можно было хранить в одном массиве указателей на функции.

## Сборка и запуск

Требуется компилятор C (GCC или Clang).

```bash
gcc main.c arrManager.c -o sortinc
./sortinc
```

В Windows запускайте `sortinc.exe`.

## Использование

После запуска программа последовательно запрашивает:

1. количество элементов массива;
2. минимальное возможное значение элемента;
3. максимальное возможное значение элемента;
4. номера алгоритмов из списка через пробел (завершение ввода — `Enter`).

Номера вне диапазона `1–5` пропускаются с предупреждением. Если минимум больше максимума, не введено ни одного корректного номера или ввод некорректен, программа завершается с сообщением об ошибке.

### Пример сеанса

```
Enter count of elements in array:
2048
Enter the minimum possible number for number generation in array:
-1000
Enter the maximum possible number for number generation in array:
1000
Select functions separated by spaces:
1. Stupid sort
2. Bubble sort
3. Insertion sort
4. Selection sort
5. Merge sort
2 3 5

Count of elements: 2048
Range: from -1000 to 1000

Bubble sort
Status: OK (sorted)
Duration: 0.012345 sec.

Insertion sort
Status: OK (sorted)
Duration: 0.004321 sec.

Merge sort
Status: OK (sorted)
Duration: 0.000210 sec.
```

- `Status: OK (sorted)` — массив отсортирован корректно, `FAILED` — есть ошибка.
- `Duration` — время работы алгоритма в секундах.

(Значения времени приведены для примера и зависят от компьютера.)

## Примечания

- Время измеряется функцией `clock()` из `<time.h>` с помощью макроса `MEASURE_TIME`.
- Макрос `MEASURE_TIME` использует расширение GNU (statement expressions), поэтому для сборки нужен GCC или Clang (MSVC не поддерживается).
- Простейшая сортировка при больших `n` работает крайне медленно — для неё лучше брать небольшие массивы.
- В `mergeSortASC` вспомогательные массивы создаются на стеке (VLA), поэтому на очень больших входных данных возможно переполнение стека.
